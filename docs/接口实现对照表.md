## 实现边界

112 个端点的实现只在 Web 版 `src/api/mock/`。`android-shell/` 把 Web 版 `dist/` 产物装进 WebView，因此复用同一套 mock 后端。`kmp/` 是 Kotlin Multiplatform 本地页面，数据源为 SQLDelight；`kmp/` 没有 HTTP 客户端、没有 Retrofit 或 Ktor 依赖，也没有 `data=` 与 `trace_id` 契约层。`kmp/` 的登录、订单、推送、配置均为本地模拟，不计入下表实现数。

## 特殊端点（逐条登记）

| 端点 | 特殊性 | 处理 |
|---|---|---|
| `Config/GetV2` | 唯一 `@Headers({"urlType:configManage"})`，走 `meow-config.aiyouaiyou.cn/api/` | `HttpTransport` 按 urlType 切 host；本地 mock 回显全部请求字段 + `remote_config` 字典 |
| `Bills/ImportBills` ×2 | 两个同名重载：`ImportBillsReq` / `ImportOcrBillsReq` | 同一处理器：`items` 数组优先，否则解析 `ocrText`/`text`/`content` 逐行建账，均写 `member_import_bill_file` |

| `Behavior/Add` | 埋点批量上报 | ➖ 保留端点 + 写 `behavior_event` 本地表，不做网络外发 |
| `Operation/*` | 运营弹窗 / 更新提醒 | ✅ 保留端点，返回可配置数据（默认 `show:0`） |
| `Upload/*` | multipart/OSS 配置 | ✅ 本地等价：`UploadImg` 返回本地 OSS 配置占位，`UploadImages`/`UploadBills` 登记文件记录 |

## 契约层约定（M2 落地，M3 统一信封语义）

- 请求：明文 JSON（原样本 `data=<native 加密串>`，`04` §5 等价替代，不复现私有加密）。
- 响应：`{ code: 0, message: "", data: {...}, trace_id: "..." }`；`Handler` 与 `Transport.send` 均返回完整信封，`call()` 解包 `data`，`code != 0` 抛 `ApiError(path, message, code)`。
- 列表包装：`Items<T>` → `{"items": [...]}`（`itemsOf()` 兼容 `items/bills/list/data` 与裸数组）。
- 时间：`yyyy-MM-dd HH:mm:ss`；`day` 为 `yyyyMMdd` 整数；预算 `day` 为 `yyyyMM`。
- 金额：整数分（`moneyCents()`，`yuanToCents()` 输入校验）。
- 幂等：`bill` 复合主键 `(member_id, client_id)`；`client_id` 为端侧幂等键。
- 超时（对齐 `d0/a.java`）：connect 30s / call 120s / read 60s / write 60s / ping 5s。
- 字段来源：`@Field → ctx.fields`、`@Body(Map/实体) → ctx.body`，`params()` 合并后按名读取（`MemberTag/Create` 保留源码大写 `BillBookId` 且兼容小写）。
