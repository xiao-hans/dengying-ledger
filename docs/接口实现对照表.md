## 契约层约定（M2 落地）

- 请求：明文 JSON（原样本 `data=<native 加密串>`，`04` §5 等价替代，不复现私有加密）。
- 响应：`{ code: 0, message: "", data: {...}, trace_id: "..." }`。
- 列表包装：`Items<T>` → `{"items": [...]}`。
- 时间：`yyyy-MM-dd HH:mm:ss`；`day` 为 `yyyyMMdd` 整数。
- 金额：整数分 `amount_cents`（`04` §7.5）。
- 幂等：`bill` 复合主键 `(member_id, client_id)`。
- 超时（对齐 `d0/a.java`）：connect 30s / call 120s / read 60s / write 60s / ping 5s。
