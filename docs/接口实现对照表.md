## 契约层约定

- 请求：明文 JSON；字段名与 `spec/endpoints.json` 一致；`Authorization`、`X-Device-Id`、`X-App-Version`、`X-Client-Time` 由拦截器注入。
- 响应：`{ code: 0, message: "", data: {...}, trace_id: "..." }`；`code != 0` 抛带 `path`、`code`、`trace_id` 的异常。
- 配置域：`Config/GetV2` 单独走 `meow-config.aiyouaiyou.cn/api/`；其余走 `puppy-api.cqmiaoa.com/api/`。
- 列表包装：`{"items": [...]}`，兼容 `items` / `bills` / `list` / `data` / 裸数组。
- 时间：`yyyy-MM-dd HH:mm:ss`；`day` 为 `yyyyMMdd` 整数；预算 `day` 为 `yyyyMM`。
- 金额：整数分；写入前校验字符串金额，禁止浮点累加。
- 幂等：`bill` 复合主键 `(member_id, client_id)`；`client_id` 为端侧幂等键。
- 超时（对齐 `d0/a.java`）：connect 30s / call 120s / read 60s / write 60s / ping 5s。
- 字段来源：`@Field` 与 `@Body` 的 key 按 `spec/endpoints.json` 注册；`MemberTag/Create` 保留源码大写 `BillBookId`，并兼容小写。
- 动态 URL：下载使用流式响应；OSS 直传使用 multipart；两者各登记一条 `@Url` 能力。

## 完整性校验

- KMP 契约清单应读取 `spec/endpoints.json`，按 112 条注解路径逐条注册；同名重载按请求体区分。
- KMP 冒烟测试应覆盖 111 个唯一路径、2 个动态 `@Url`、`Config/GetV2` 的独立 host 与统一响应解包。
- KMP 验证命令：`:shared:jvmTest`、`:app:assembleDebug`；Android 能力在真机或仪器测试验证。
- Web 规格参考校验记录：`src/api/mock/index.ts` 的 `verifyEndpoints(expected)` 与 `src/api/mock/selftest.ts` 的 `apiSelfTest(endpoints)` 曾核对 `want 111 handlers 111`、`MISSING: (空)`、`EXTRA: (空)`；该记录不计入 KMP 验收。
- 广告依赖黑名单属于 S8 全量回归门禁。
