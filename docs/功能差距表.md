# KMP 全量复刻功能差距表

本表登记 2026-11-11 的 KMP 实现状态。状态列只使用「已实现」「未实现」「无广约束」「待证据」。「已实现」表示 KMP 有对应代码，且计划中的验证已完成；「未实现」表示 KMP 没有对应代码；「待证据」表示现有文档不足以确定验收条件。

`01` 指 `D:\workspace\recordAccount\01-功能点全量清单.md`，`02` 指 `D:\workspace\recordAccount\02-业务架构.md`。`spec/endpoints.json` 是 112 个注解路径的权威清单。Web 版和 `android-shell/` 不计入 KMP 实现状态。

## 6. 更新规则

1. 每个切片完成后，执行者应更新本表对应模块、端点、页面、表和门禁的状态。
2. 执行者应把「已实现」对应的代码路径写进「KMP 实现位置」列。
3. 执行者应在实施计划记录提交号、构建结果和真机结果。
4. 如果代码删除或功能回退，执行者应把状态改回「未实现」。
5. 如果想把「待证据」改成「已实现」，执行者应先补验证命令与输出记录。
6. S8 完成前，本表不得出现空白状态列。
